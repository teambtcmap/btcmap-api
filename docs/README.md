# BTC Map API Documentation  

This documentation describes the BTC Map API, including available interfaces and usage guidelines.

## Available Interfaces  

### REST API

Best choice for client apps and simple read-only integrations.

[Read REST docs](rest/README.md)

Some of the apps using REST interface:

- [Our official website](https://btcmap.org/)
- [Our official Android app](https://f-droid.org/packages/org.btcmap/)
- [Our official iOS app](https://apps.apple.com/us/app/btc-map/id6443604345)
- [BTC Map Telegram Bot](https://github.com/beinardus/BTCMapBot)
- [CoinOS](https://coinos.io/)
- [Square Cash App](https://cash.app/)

### RPC API

Admin interface used by our community managers and trusted partners. Most calls require privileged access.

[Read RPC docs](rpc/README.md)

Some of the apps using RPC interface:

- [Our official dashboard](https://dashboard.btcmap.org/)
- [Our official area admin app](https://admin.btcmap.org/)
- [Our official event admin app](https://eventadmin.btcmap.org/)
- [Club Orange place import pipeline](https://www.cluborange.org/)
- [Square place import pipeline](https://cash.app/)
